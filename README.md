# 가족 발명소

학생과 보호자가 대화하며 불편을 찾고 3D펜으로 함께 해결해 보는 수업 웹앱.

## 로컬 실행

Node.js 20.9 이상과 npm이 필요합니다.

```sh
npm install
npm run dev
```

PC: http://localhost:3000. 같은 네트워크의 iPad: 개발 서버가 출력한 Network 주소로 접속합니다. 방화벽과 학교 Wi-Fi의 기기 간 접속 정책에 따라 접근이 제한될 수 있습니다.

```sh
npm run typecheck
npm run build
npm start
```

## 현재 제공하는 기능

- 8단계 수업 안내: 시작·불편 발견·설계·안전·연습·제작·소개·추억
- 보호자 대화 질문, 불편·첫 생각·발명품 기록
- Solar/예비 힌트 3장과 단순화·2조각·다른 힌트, 선택 시 부품 계획에 반영
- 안전 확인 6개 완료 후 가족 화면에서 펜 연습·제작 진입
- 실제 조각 3개 이내로 역할과 완성 여부 기록, 조립 순서
- 단계별 수동 타이머, 제작 단계 25분/23분, 소개 90초
- 교사 큰 화면과 진행 메모, 전체 시간표, 활동 기록 인쇄/PDF
- 태블릿 세로·가로와 작은 화면을 위한 Swiss Modernism 스타일

입력은 React 메모리에만 유지합니다. 새로고침·탭 닫기 시 사라집니다. 서버 DB·사용 기록 저장·로그인·사진 수집은 없습니다. 가족별 진행은 독립적이며 교사와 실시간 동기화하지 않습니다. 인쇄/PDF 버튼은 브라우저의 인쇄 화면을 엽니다.

## 현재 단계와 제한

전체 수업 흐름과 Solar 서버 연동 코드를 구현한 MVP입니다. 실제 API 키는 아직 등록하지 않았으며 실 API 호출은 검증 전입니다. 키·사용 스위치·이용 시간·요청 제한 조건을 갖추면 Solar를 호출하고, 그 외에는 예비 힌트를 제공합니다. 예비 힌트와 AI 결과 모두 실제 제작 검증이 필요합니다.

화면을 이미 연 상태에서 API 요청이 실패하면 브라우저에 포함된 예비 힌트를 표시합니다. 완전한 오프라인 최초 실행·재실행을 지원하는 PWA는 아닙니다. 인터넷 장애 대비로 수업 자료와 예비 힌트를 미리 인쇄하세요. manifest와 SVG 아이콘을 제공하지만 iPad 홈 화면 아이콘과 인쇄/PDF는 실기기 확인이 필요합니다.

개발 환경의 네트워크 제한은 로컬 캐시를 사용해 설치 단계에서 해결했습니다. 버전과 `package-lock.json`을 고정했습니다. 제한된 Windows 환경에서 빌드가 가능하도록 `next.config.ts`에 스레드 기반 작업과 TypeScript API 검사를 설정했습니다. 첫 버전은 GitHub `main`에 푸시했습니다(`d30c5a6`). `.git/config` 수정은 제한되어 원격 URL을 직접 지정해 푸시했습니다.

## Solar 설정

`.env.example`을 `.env.local`로 복사하고 로컬에서 값을 등록합니다. `.env.local`은 Git에서 제외됩니다. Vercel 배포 시에는 같은 값을 서버 환경변수로 등록합니다.

| 환경변수 | 설명 |
| --- | --- |
| `SOLAR_API_KEY` | Upstage 키. 브라우저로 보내지 않음 |
| `SOLAR_ENABLED` | `true`일 때만 호출. `false`로 즉시 비활성화 |
| `SOLAR_MODEL` | 기본 `solar-mini4`. 사용할 모델로 변경 가능 |
| `SOLAR_API_ENDS_AT` | 시간대가 포함된 종료 시각. 기본 예시는 `2026-10-24T11:30:00+09:00` |
| `SOLAR_MAX_REQUESTS_PER_MINUTE` | 전체 분당 요청 수, 기본 30, 설정 가능 범위 1~60 |
| `SOLAR_MAX_REQUESTS_PER_DAY` | 전체 한국 날짜 기준 일일 요청 수, 기본 200, 설정 가능 범위 1~1000 |
| `SOLAR_BUDGET_SCOPE` | 공유 카운터 이름. 기본 `family-2026-10-24` |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | 공개 배포에서 필요한 공유 호출 카운터 연결 정보 |

개발 서버(`npm run dev`)에서는 메모리 카운터를 사용할 수 있습니다. 프로덕션(`npm start`, Vercel)에서는 공유 카운터 연결이 없거나 오류가 나면 Solar 호출을 중단하고 예비 카드를 표시합니다. 공유 저장소에는 전체 호출 횟수만 두며 가족 입력·AI 응답·IP·기기 식별자는 저장하지 않습니다. 서비스나 계정은 자동으로 생성하지 않았습니다.

요청은 카운터에서 먼저 예약하므로 Solar 오류도 요청 수에 포함됩니다. 이 한도는 요청 수 기준이며 결제 금액 자체의 상한은 아닙니다. 분당 제한은 고정된 분 구간 기준입니다. 기본 한도는 행사 리허설 결과에 따라 조정합니다.

AI를 요청하면 불편과 이전 힌트가 Solar로 전송됩니다. 개인정보를 적지 않도록 안내하며 연락처·이메일 패턴은 서버에서 거부합니다. 모든 개인정보나 위험한 제안을 자동으로 찾아내는 것은 보장하지 않습니다.

서버는 카운터 처리와 생성·응답 읽기를 합해 13.5초로 제한하고 브라우저는 15초 뒤 예비 힌트로 전환합니다. JSON 스키마·카드 3개·조각 수·중복 이름·일부 금지 표현·cm/mm 크기를 검증합니다. 2조각 요청은 최대 2개, 다른 힌트 요청은 이전 이름 반복을 거부합니다. 종료 시각이 지났거나 설정이 잘못된 경우에도 예비 카드로 진행합니다.

API 형식 참고: [Upstage Chat API](https://console.upstage.ai/api/chat), [Upstash REST API](https://upstash.com/docs/redis/features/restapi). Upstash는 호출 카운터용 선택 구현이며, 다른 배포 보호 방식을 채택하면 서버의 카운터 모듈을 교체할 수 있습니다.

## 확인 결과 (2026-10-15)

- `npm run typecheck`: 통과
- `npm run build`: 통과 (`/` 정적 페이지, `/api/ideas` 서버 경로)
- Chrome: 첫 화면, 안전 확인 전 펜 단계 진입 안내, 6개 확인 후 연습 진입, 불편의 설계 단계 전달, 카드 3장, 선택한 카드의 조각 계획 반영 확인
- Chrome 810×1080 화면: 세로 레이아웃 시각 확인. 실제 iPad Safari 검증은 아직 하지 않음
- 예비 카드 API: 정상 200, 카드 3장, 다른 힌트 변경, 2조각 제한, 51자 입력 거부(400), 동시 요청 8건 성공
- Solar 모듈·API 경로 모의 확인 18개 통과: 정상 응답, 키 오류, 시간 초과, 잘못된 JSON, 조각·중복·위험 표현·크기 검증, 연락처·출처·본문 크기 검증, 종료 차단, 공유 제한 누락·거부·허용. 외부 API나 실제 Redis는 호출하지 않음
- 미확인: 인쇄/PDF의 실제 출력, 학교 Wi-Fi·실제 iPad·홈 화면 아이콘, 실제 Solar API, 작품 제작 가능성

동시 요청 결과는 정적 예비 카드 API에 대한 로컬 확인이며 Solar 성능이나 학교 환경의 동작을 보장하지 않습니다.

## 수업 재사용

`src/lib/camp.ts`에서 제목·일시·장소·미션·질문·기기·안전 안내·단계·시간·교사 메모를 바꿉니다. `src/lib/ideas.ts`에서 주제별 예비 힌트를 바꿉니다. 현재는 3D펜 제작을 위한 공통 8단계 틀입니다. 겨울 캠프에서는 대상과 재료에 맞는 내용으로 교체할 수 있으며, 임의의 다른 교과를 위한 수업 편집기는 포함하지 않습니다.
