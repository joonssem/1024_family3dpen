# 가족 발명소

학생과 보호자가 대화하며 불편을 찾고 3D펜으로 함께 해결해 보는 수업 웹앱.

접속 주소: **https://project-c9pas.vercel.app** (2026-10-19 배포). 현재 배포의 AI는 비활성화되어 준비된 힌트로 진행하며, 수업 안내와 QR 기록 저장은 사용할 수 있습니다.

## 로컬 실행

Node.js 20.9 이상과 npm이 필요합니다.

```sh
npm install
npm run dev
```

PC: http://localhost:3000. 같은 네트워크의 iPad: 개발 서버가 출력한 Network 주소로 접속합니다. 방화벽과 학교 Wi-Fi의 기기 간 접속 정책에 따라 접근이 제한될 수 있습니다.

```sh
npm run typecheck
npm run test:server
npm run test:record
npm run build
npm start
```

## 현재 제공하는 기능

- 8단계 수업 안내: 시작·불편 발견·설계·안전·연습·제작·소개·추억
- 보호자 대화 질문, 불편·첫 생각·발명품 기록
- Solar/예비 힌트 3장과 단순화·2조각·다른 힌트, 선택 시 부품 계획에 반영
- 안전 확인 6개 완료 후 가족 화면에서 펜 연습·제작 진입
- 실제 조각 3개 이내로 역할과 완성 여부 기록, 조립 순서
- 단계별 수동 타이머, 제작 단계 25분/23분, 소개 90초
- 교사 큰 화면과 진행 메모, 전체 시간표
- 활동 기록 QR 전달 → 보호자 스마트폰에서 PNG 이미지 저장·공유
- 태블릿 세로·가로와 작은 화면을 위한 Swiss Modernism 스타일

수업 입력은 React 메모리에만 유지합니다. 새로고침·탭 닫기 시 사라집니다. 서버 DB·사용 기록 저장·로그인·사진 수집은 없습니다. 가족별 진행은 독립적이며 교사와 실시간 동기화하지 않습니다. 앱 화면에는 고정된 참여 가족 수를 표시하지 않습니다.

## 보호자 스마트폰으로 활동 기록 가져가기

1. ‘추억 남기기’에서 소감을 적고 **우리 가족 기록 QR로 가져가기**를 누릅니다.
2. 보호자 스마트폰 카메라로 QR을 찍어 기록 화면을 엽니다.
3. **기록 이미지 저장**으로 PNG를 다운로드합니다. 지원 기기에서는 공유 메뉴로 사진 앱에도 저장할 수 있습니다. 이미지 길게 누르기도 지원합니다.
4. 저장한 내용을 확인한 뒤 수업 iPad에서 ‘새 가족으로 시작’을 누릅니다. 이미 전달된 링크와 이미지는 iPad를 초기화해도 유지됩니다.

불편·첫 생각·발명품·바꾼 점·선택한 힌트·조각별 모양과 담당·완성 여부·조립 순서·학생과 보호자의 소감을 한 이미지로 담습니다. 기록을 수정했다면 QR을 다시 만드세요. 빈 칸은 대화를 나눴다는 기본 문구로 표시하며, 사진은 포함하지 않습니다.

기록은 압축해 `/record#v1.…` 링크의 fragment에 담습니다. fragment는 HTTP 요청으로 서버에 전달되지 않으며, 스마트폰 브라우저가 기록을 복원하고 Canvas로 PNG를 만듭니다. QR과 링크 자체에는 기록이 들어 있으므로 받은 사람이 내용을 볼 수 있습니다. 링크는 암호화·접근 제한·만료 기능이 없고 브라우저 방문 기록에 남을 수 있습니다. QR 생성 서비스나 이미지 업로드 저장소를 사용하지 않습니다.

양쪽 기기에서 접속할 수 있는 배포 URL 사용을 권장합니다. `localhost`·루프백 주소에서는 스마트폰으로 열 수 없으므로 QR 대신 접속 주소 안내와 현재 기기의 이미지 저장을 제공합니다. 학교 네트워크 주소는 보호자 스마트폰에서도 접속 가능해야 하며 Wi-Fi의 기기 간 통신 정책에 따라 제한될 수 있습니다. 인터넷 없는 최초 접속은 지원하지 않습니다. 아주 긴 기록으로 QR 용량을 초과하면 내용을 줄여 다시 생성하거나 현재 기기에 이미지를 저장해 전달하도록 안내하며 기록을 임의로 자르지 않습니다.

검증 명령: `npm run test:record`는 기록 압축·복원·스키마 검증과 생성한 QR 판독을 확인합니다. 앱 실행 후 `npm run check:record-browser`는 별도 Chrome에서 iPad 크기의 QR 생성 → 스마트폰 크기의 PNG 다운로드·새로고침·초기화 후 링크 유지·잘못된 링크를 점검하고 `artifacts/record-qa/`에 예시 이미지와 화면을 저장합니다. Windows의 설치된 Chrome을 사용하며 다른 환경은 Playwright Chromium 설치 또는 `BROWSER_PATH` 지정이 필요합니다. 학교의 실제 iPad·스마트폰 카메라·사진 앱 저장 동작은 현장에서 확인해야 합니다.

## 현재 단계와 제한

전체 수업 흐름과 Solar 서버 연동 코드를 구현한 MVP입니다. 2026-10-19 실제 Vercel 프로젝트를 조회해 운영 환경에 Solar 키와 설정이 이미 등록되어 있음을 확인했습니다. 키 값은 읽거나 출력하지 않았습니다. 로컬 설정에는 키가 없고, 운영 환경의 공유 요청 카운터는 미등록입니다. 이번 배포에는 `SOLAR_ENABLED=false`를 별도 적용했으며 실제 Solar 호출은 검증 전입니다. 키·사용 스위치·이용 시간·요청 제한 조건을 갖추면 Solar를 호출하고, 그 외에는 예비 힌트를 제공합니다. 예비 힌트와 AI 결과 모두 실제 제작 검증이 필요합니다.

화면을 이미 연 상태에서 API 요청이 실패하면 브라우저에 포함된 예비 힌트를 표시합니다. 완전한 오프라인 최초 실행·재실행을 지원하는 PWA는 아닙니다. 인터넷 장애 대비로 수업 자료와 예비 힌트를 미리 인쇄하세요. manifest와 SVG 아이콘을 제공하지만 iPad 홈 화면 아이콘과 QR·이미지 저장은 실기기 확인이 필요합니다.

개발 환경의 네트워크 제한은 로컬 캐시를 사용해 설치 단계에서 해결했습니다. 버전과 `package-lock.json`을 고정했습니다. 제한된 Windows 환경에서 빌드가 가능하도록 `next.config.ts`에 스레드 기반 작업과 TypeScript API 검사를 설정했습니다. 첫 버전은 GitHub `main`에 푸시했습니다(`d30c5a6`). `.git/config` 수정은 제한되어 원격 URL을 직접 지정해 푸시했습니다.

## Solar 설정

`.env.example`을 `.env.local`로 복사하고 로컬에서 값을 등록합니다. `.env.local`은 Git에서 제외됩니다. Vercel 배포 시에는 같은 값을 서버 환경변수로 등록합니다.

로컬 `.env.local`에 키와 `SOLAR_ENABLED=true`를 등록한 뒤 `npm run dev`로 앱을 실행합니다. 환경변수 변경 후에는 개발 서버를 다시 시작합니다. 별도 터미널에서 `npm run check:solar`를 실행하면 수업용 예시 한 건으로 실제 연결 여부와 소요 시간을 확인합니다. 예비 카드로 전환되면 필요한 설정을 안내합니다. 키와 응답 본문은 출력하지 않습니다. 종료 코드는 성공 0, 연결·응답 오류 1, 예비 전환 2입니다.

배포 후에는 `npm run check:solar -- https://배포주소`로 같은 확인을 할 수 있습니다. 한 번 실행할 때 AI 요청 한 건이 발생할 수 있습니다.

| 환경변수 | 설명 |
| --- | --- |
| `SOLAR_API_KEY` | Upstage 키. 브라우저로 보내지 않음 |
| `SOLAR_ENABLED` | `true`일 때만 호출. `false`로 즉시 비활성화 |
| `SOLAR_MODEL` | 기본 `solar-mini4`. 사용할 모델로 변경 가능 |
| `SOLAR_API_ENDS_AT` | 시간대가 포함된 종료 시각. 기본 예시는 `2026-10-24T11:30:00+09:00` |
| `SOLAR_MAX_REQUESTS_PER_MINUTE` | 전체 분당 요청 수, 기본 30, 설정 가능 범위 1~60 |
| `SOLAR_MAX_REQUESTS_PER_DAY` | 전체 한국 날짜 기준 일일 요청 수, 기본 200, 설정 가능 범위 1~1000 |
| `SOLAR_BUDGET_SCOPE` | 공유 카운터 이름. 기본 `family-2026-10-24` |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | 공개 배포에서 필요한 공유 호출 카운터 연결 정보 |

개발 서버(`npm run dev`)에서는 메모리 카운터를 사용할 수 있습니다. 프로덕션(`npm start`, Vercel)에서는 공유 카운터 연결이 없거나 오류가 나면 Solar 호출을 중단하고 예비 카드를 표시합니다. 공유 저장소에는 전체 호출 횟수만 두며 가족 입력·AI 응답·IP·기기 식별자는 저장하지 않습니다. 서비스나 계정은 자동으로 생성하지 않았습니다.

요청은 카운터에서 먼저 예약하므로 Solar 오류도 요청 수에 포함됩니다. 이 한도는 요청 수 기준이며 결제 금액 자체의 상한은 아닙니다. 분당 제한은 고정된 분 구간 기준입니다. 기본 한도는 행사 리허설 결과에 따라 조정합니다.

AI를 요청하면 불편과 이전 힌트가 Solar로 전송됩니다. 개인정보를 적지 않도록 안내하며 연락처·이메일 패턴은 서버에서 거부합니다. 모든 개인정보나 위험한 제안을 자동으로 찾아내는 것은 보장하지 않습니다.

서버는 카운터 처리와 생성·응답 읽기를 합해 13.5초로 제한하고 브라우저는 15초 뒤 예비 힌트로 전환합니다. JSON 스키마·카드 3개·조각 수·중복 이름·일부 금지 표현·cm/mm 크기를 검증합니다. 2조각 요청은 최대 2개, 다른 힌트 요청은 이전 이름 반복을 거부합니다. 종료 시각이 지났거나 설정이 잘못된 경우에도 예비 카드로 진행합니다.

API 형식 참고: [Upstage Chat API](https://console.upstage.ai/api/chat), [Upstash REST API](https://upstash.com/docs/redis/features/restapi). Upstash는 호출 카운터용 선택 구현이며, 다른 배포 보호 방식을 채택하면 서버의 카운터 모듈을 교체할 수 있습니다.

## 확인 결과 (2026-10-15)

- `npm run typecheck`: 통과
- `npm run build`: 통과 (`/` 정적 페이지, `/api/ideas` 서버 경로)
- Chrome: 첫 화면, 안전 확인 전 펜 단계 진입 안내, 6개 확인 후 연습 진입, 불편의 설계 단계 전달, 카드 3장, 선택한 카드의 조각 계획 반영 확인
- Chrome 810×1080 화면: 세로 레이아웃 시각 확인. 실제 iPad Safari 검증은 아직 하지 않음
- 예비 카드 API: 정상 200, 카드 3장, 다른 힌트 변경, 2조각 제한, 51자 입력 거부(400), 동시 요청 8건 성공
- Solar 모듈·API 경로 모의 확인 18개 통과: 정상 응답, 키 오류, 시간 초과, 잘못된 JSON, 조각·중복·위험 표현·크기 검증, 연락처·출처·본문 크기 검증, 종료 차단, 공유 제한 누락·거부·허용. 외부 API나 실제 Redis는 호출하지 않음
- 미확인: 인쇄/PDF의 실제 출력, 학교 Wi-Fi·실제 iPad·홈 화면 아이콘, 실제 Solar API, 작품 제작 가능성

동시 요청 결과는 정적 예비 카드 API에 대한 로컬 확인이며 Solar 성능이나 학교 환경의 동작을 보장하지 않습니다.

## 후속 점검 (2026-10-19)

- 교사 화면에서 안전 확인 없이 연습·제작 단계로 이동한 뒤 가족 화면으로 돌아오면 안전 약속 단계로 안내하도록 수정했습니다. 진행 중인 타이머도 멈춥니다.
- 연락처 등 잘못된 입력을 서버가 거부하면 입력 수정 안내를 표시합니다. 이 경우 연결 장애용 예비 카드로 덮어쓰지 않고 바로 다시 요청할 수 있습니다.
- 힌트 입력칸에 AI 요청 시 불편과 이전 힌트가 Upstage Solar로 전송된다는 안내를 추가했습니다.
- `npm run build`, `npm run typecheck` 통과. 실행 중인 개발 서버에서 첫 페이지 HTTP 200, 예비 카드 3장, 2조각 제한, 다른 힌트의 이전 이름 제외, 이메일·51자 입력 거부, 다른 출처 요청 거부, 예비 카드 동시 요청 8건을 확인했습니다.
- `npm run check:solar`는 예비 전환(종료 코드 2)을 확인했습니다. 로컬 Solar 키·활성화 및 Upstash 연결은 미설정이며, 실제 외부 AI 호출은 수행하지 않았습니다.
- 브라우저 자동화 도구가 시작 경로 오류로 실행되지 않아 이번 화면 조작·시각 검증은 미완료입니다. 가족 화면 복귀 시 안전 차단, 잘못된 입력 안내와 수정 후 재요청, iPad Safari, 인쇄/PDF는 화면에서 추가 확인해야 합니다.
