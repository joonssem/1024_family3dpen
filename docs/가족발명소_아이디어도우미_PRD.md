# 가족 발명소 수업 웹앱 PRD

> **v2 · 2026-10-15 사용자 인터뷰 반영**: AI 힌트 전용 앱에서 수업 전체를 안내하는 웹앱으로 확대한다. 아래 「10. 인터뷰 확정 사항과 변경 요구사항」이 앞선 초안보다 우선한다. 기존 파일명은 참조 유지를 위해 보존한다.

10월 24일 「AI 아이디어를 입체로 만드는 가족 발명소」에서 보호자가 쓰는 웹페이지를 정의한다. 교육적 기준과 행사 흐름은 [[2026-10-24-가족-발명소-3D펜-활동-운영안]]을 따른다.

> 소스코드는 Drive 밖 로컬 폴더의 별도 Git 저장소에서 개발한다. 이 문서에는 요구사항, 저장소·배포 링크, 수업 적용 결과만 남긴다.

## 1. 해결할 문제

- 보호자는 오늘 아이의 **'AI 역할'**을 맡아 질문으로 아이디어를 넓혀 준다. 그래도 가족이 함께 막힐 때 바로 꺼내 볼 힌트가 필요하다.
- 교사는 1명이라 7팀을 동시에 도울 수 없다.
- 학생 계정은 13세 미만이라 Copilot을 쓸 수 없고, 행사 중에 계정·로그인 문제를 처리할 여유가 없다.

| 기기 | 학교 공용 아이패드 9세대 8대(팀당 1대 + 예비 1대), Safari, 홈 화면 바로가기 |

## 3. 핵심 사용 흐름

1. **불편 입력**: "책상이나 방에서 불편한 점을 한 가지 적어 주세요." 입력칸 1개와 힌트 버튼(자꾸 굴러가요 / 자주 잃어버려요 / 줄이 엉켜요 / 놓을 자리가 없어요)을 둔다.
2. **아이디어 카드 3장**: 카드마다 다음을 보여 준다.
   - 발명품 이름
   - 어떤 불편을 해결하는지 한 줄
   - 부품 **3개 이내**와 각 부품의 모양(예: 동그라미 받침, 네모 벽 2장)
   - 이어 붙이는 방법 한 줄
3. **다시 묻기 버튼**: 「더 간단하게」, 「부품 2개로」, 「다른 아이디어」. 질문을 바꾸면 답이 달라진다는 것도 배움이 된다.
4. **카드 아래 고정 안내**: "AI 답은 힌트예요. 고르거나 바꾸는 것은 아이가 해요."

## 4. AI 질문 틀 (서버에서 사용)

운영안의 질문 틀을 그대로 쓴다. `[불편]`만 사용자 입력으로 바꾼다.

> 초등학생과 부모님이 3D펜으로 30분 안에 손바닥 크기로 만들 수 있는 물건 아이디어 3가지를 알려줘. 해결하고 싶은 불편은 "[불편]"이야. 각 아이디어는 부품 3개 이내로, 어떤 모양을 이어 붙이면 되는지 짧게 설명해 줘.

추가 조건(시스템 지시로 넣는다):

- 문장은 3학년이 읽을 수 있게 짧게 쓴다.
- 손바닥 크기(약 10cm 이내), 평면 부품을 그려 세우고 붙이는 방식으로 만들 수 있어야 한다.
- 위험한 물건, 전기·불·칼 관련 물건, 먹을 것을 담는 그릇은 제안하지 않는다.
- 카드 3장을 정해진 구조(JSON 등)로 돌려주어 화면에 카드로 그린다.

## 10. 인터뷰 확정 사항과 변경 요구사항 (v2)

### 가장 중요한 목표

학생이 학교에서 보호자와 안전하게 대화하며 미션을 수행하고 추억을 만든다. 학생이 불편을 발견하고 해결 방향을 결정한다. 보호자는 질문하고 함께 만들며 안전을 돕는다. 학생과 보호자의 만족이 우선이다.

정교한 실용품의 완성 여부보다 주어진 시간 안에 함께 문제를 해결해 보는 경험을 중시한다. 미완성 부품과 스케치도 소개할 수 있다. AI는 꼭 써야 하는 도구가 아니다.

### 확정된 여건

- 3D펜: **RP800A 15대 이상**, PLA, **190℃ 기준**. 사용자 확인 정보다.
- 제품: https://item.gmarket.co.kr/Item?goodsCode=1912007393 — 개발 환경에서 제품 페이지는 열리지 않았다.
- 개발 위치: `D:\Projects\1024_family3dpen`.
- 원격 저장소: https://github.com/joonssem/1024_family3dpen.
- 배포 계획: Vercel. 현재 미배포.
- 디자인: **Swiss Style / Swiss Modernism**. 명확한 격자, 굵은 제목, 정렬된 레이아웃, 제한된 색상.
- 안전 안내는 190℃ 기준으로 조정한다. 정확한 재료 퇴출 시간·거치 방식은 RP800A 설명서와 실물 시연으로 확인한다. 과거 자료의 5초 규칙을 그대로 확정하지 않는다.

### 수업 전체를 앱에서 안내

| 단계 | 시간 | 주요 역할 |
| --- | --- | --- |
| 함께 시작 | 09:00~09:08 | 오늘의 목표·가족 역할·교사 AI 맛보기 |
| 불편 발견 | 09:08~09:14 | 보호자 질문, 학생의 경험과 첫 생각 |
| 아이디어 설계 | 09:14~09:20 | 학생의 선택, 선택적 힌트, 종이 스케치 |
| 안전 약속 | 09:20~09:25 | 안전 안내 6개 확인 |
| 3D펜 첫걸음 | 09:25~09:40 | 점·선·면과 조립 원리, 교사 시연 따라 하기 |
| 함께 만들기 | 09:50~11:03 | 역할 나누기·조각 만들기·조립 |
| 발명품 소개 | 11:03~11:15 | 가족당 90초, 불편·바꾼 생각·함께한 경험 |
| 추억 남기기 | 11:15~11:20 | 학생·보호자 소감, 기록 인쇄/PDF, 안전 마무리 |

09:40~09:50, 10:30~10:40은 휴식·환기다. 발견·설계 6분씩 배분은 앱 초안이며 교사가 12분 안에서 조정할 수 있다. 실제 주 제작은 부품 25분 + 조립 23분이다. AI의 30분 조건은 제작 여유를 두는 난이도 목표로 사용한다.

### 추가 P1

- 전체 수업 단계·휴식·마무리 안내, 자유로운 단계 이동
- 보호자 대화 질문과 아이 생각을 먼저 듣는 안내
- 선택적 기록: 불편·첫 생각·발명품 이름·바꾼 점·학생과 보호자 소감
- 안전 약속 6개 확인 후 가족 화면에서 펜 연습·제작 진입. 교사 화면은 설명을 위해 자유 이동
- **실제 만드는 조각 합계 3개 이내**. 같은 벽 두 장은 2개로 계산
- 조각별 이름·모양·담당·완성 여부와 조립 순서
- 수동 활동 타이머, 소개 90초 타이머
- 교사 큰 화면·진행 메모, 가족 기록 인쇄/PDF
- AI 없이도 수업 전 과정을 진행

### 겨울 캠프 재사용

수업 제목·일시·장소·미션·질문·기기·안전·단계·시간·교사 메모는 `src/lib/camp.ts`에 모은다. 예비 힌트는 `src/lib/ideas.ts`에서 바꾼다. 겨울 학생 캠프에서는 보호자 역할 문구를 짝 활동 문구로 교체한다. 현재는 3D펜 수업을 위한 공통 8단계 틀이며 임의 수업을 위한 편집기는 만들지 않는다.

### 인터뷰 답변 대기 항목과 현재 초안

- 단계 이동: 가족이 직접 넘기고 교사가 말로 안내. 원격 동기화 없음.
- 입력 기록: 현재 화면의 메모리에만 유지. 새로고침·닫기 시 삭제, 마지막에 인쇄/PDF로 남김. 앱 입력 대신 종이 활동지를 써도 됨.
- DB·로그인·자유 채팅·이미지 생성·사진 업로드는 도입하지 않음.

### 장애 대비의 범위

이미 열린 앱에서 API 오류·15초 지연·응답 검증 오류가 나면 브라우저에 포함된 예비 힌트를 제공한다. 정적 카드를 포함하는 것만으로 인터넷 없는 최초 접속·재실행을 보장하지 않는다. 교사 시간표·안전 안내·보호자 질문·예비 카드를 인쇄 또는 별도 저장한다.

### 개발 상태

- 2026-10-15: 전체 수업 로컬 MVP 소스 작성. Next.js·React·TypeScript·Zod와 직접 작성한 CSS 사용. CSS로 격자·타이포그래피를 일관되게 관리한다.
- `/api/ideas`는 현재 예비 카드만 반환한다. 실제 Solar 연결은 첫 화면 검토 이후 진행한다.
- 실 API 연결 시 입력·출력 검증, 15초 제한, 이전 답을 고려한 재질문, 서버 키 보호, 배포 환경의 요청 제한·비용 보호·행사 종료 차단을 구현한다.
- 로컬 캐시로 설치 완료. TypeScript 검사·프로덕션 빌드 통과. Chrome에서 주요 흐름과 810×1080 레이아웃을 확인했고 예비 카드 API 동시 요청 8건이 성공했다. 실제 iPad Safari·인쇄·실제 Solar 연결은 미확인이다.
- 로컬 Git 초기화 완료. GitHub 접속과 `.git/config` 쓰기가 제한되어 원격 설정·푸시는 완료하지 못했다.
- 기존 `sticker-wall-ai` Worker는 사용·수정하지 않는다.

### 추가 완성 기준

- [ ] 학생 생각 → 보호자 질문 → 필요할 때 힌트의 순서가 유지된다.
- [ ] RP800A 실물 시연과 안전 안내가 일치한다.
- [ ] AI 없이도 7가족이 수업·소개·정리를 시간 안에 진행한다.

- [ ] 인쇄/PDF·새 가족 초기화·새로고침 시 기록 정책이 동작한다.
